# SEOULMATE

Static site for GitHub Pages with clean URLs (/about, /recommend, /privacy, /terms).

- Host it at the root of a domain: a custom domain like seoulmate.travel, or a username.github.io repo.
- Firebase config: assets/firebase-config.js
- Site code: assets/app.js, styles: assets/style.css
- Route finder Worker URL: search ROUTE_WORKER_URL in assets/app.js
- Social preview image: og-image.jpg. Sitemap and canonical URLs use https://seoulmate.travel
